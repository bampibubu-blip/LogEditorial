# 🗃 Log Editorial

RisuAI 채팅 로그를 **아카라이브에 올리기 좋은 에디토리얼 스타일 HTML**로 만들어 주는 플러그인입니다.

- RisuAI 플러그인 API 3.0
- 버전 1.0.0

## 설치

1. 이 저장소의 `LogEditorial.js` 파일을 받습니다.
2. RisuAI → 설정 → 플러그인 → 플러그인 추가에서 파일을 불러옵니다.
3. 채팅창에 버튼이 생기면 설치 완료입니다.

새 버전이 나오면 RisuAI 플러그인 설정에서 업데이트를 받을 수 있어요.

> 테스트 버전(Folio)을 쓰셨다면 Folio 플러그인은 지워 주세요. 저장해 둔 설정은 그대로 이어받습니다.

## 사용 순서

1. 채팅에서 버튼을 누르고, **불러올 범위**(최근 N개 / 직접 지정 / 전체)를 고릅니다.
2. 왼쪽 탭에서 표지, 등장인물, 챕터, 스타일을 정합니다. 오른쪽 미리보기에 바로 반영돼요.
3. **내보내기** 탭에서 편마다 **리치 복사**를 누릅니다.
4. 아카라이브 글쓰기 **일반 모드**에 붙여넣으면 사진까지 자동으로 올라갑니다.

## 주요 기능

**본문**
- 에셋메이드 삽화: 선택된 이미지 1장만, 재생성 이력은 제외
- 원문 / GigaTrans 번역문 / 번역 캐시 선택
- `<Thoughts>` 등 숨김 태그 제거, `{{char}}` `{{user}}` 치환
- 일반 치환과 정규식 치환 (`$1` 그룹 참조, 플래그 지정)
- 메시지 편집, 미리보기에서 바로 고치기
- 이미지 직접 추가 (기기에서 고르기 / 주소)

**구성**
- 마스트헤드, 표지 (라벨 기본값 `{{char}} × {{user}}`)
- 등장인물 카드 최대 6명 (캐릭터·유저 포함)
- 챕터 나누기, 챕터별 접기 토글, 명대사 카드
- 삽화 캡션 문구 직접 지정 (`PLATE {n}`, `그림 {i}.` 등, 삽화별 개별 캡션)
- 유저/캐릭터 구분: 카드 · 흐리게 · 이름표 · 구분 없음, 유저 메시지 빼기

**디자인**
- 색 테마 프리셋 12종 (밝은 8 · 어두운 4)
- 기본 색 몇 가지로 만드는 내 테마, 세부 색상 조정, 저장
- 서체: 명조 / 프리텐다드 / 혼합
- 대사 표시: 형광펜 밑줄 · 글자색 · 하이라이트, 드롭캡

**아카라이브 대응**
- 인라인 스타일만 사용 (flex·grid·table·hr 없음), 다크 모드에서도 색 고정
- 보이는 글자수 기준 자동 분할 (기본 60,000자) 또는 한 편으로 합치기
- 편끼리 이전/다음 링크 연결
- 소스 복사(코드보기용)와 아카 업로드 주소 자동 연결도 지원

## 아카라이브에 올릴 때

- **리치 복사 → 일반 모드 붙여넣기**가 가장 간단합니다. 챕터 토글은 펼친 상태로 들어갑니다.
- 토글 접힘 상태까지 그대로 쓰고 싶다면 **소스 복사 → 코드보기 붙여넣기**를 쓰세요. 이때 사진은 삽화 탭에서 아카 주소를 연결해야 합니다.
- 보이는 글자가 약 70,000자를 넘으면 글이 올라가지 않을 수 있습니다. 자동 분할을 켜 두는 것을 권장합니다.

## 알아 두기

- 직접 올린 이미지는 세이브 파일이 무거워지지 않도록 **기기에만** 저장됩니다. 다른 기기에서는 보이지 않습니다.
- 프리텐다드 서체는 읽는 사람 기기에 없으면 기본 고딕체로 보입니다.
- 미리보기에서 직접 고친 메시지는 그 내용으로 고정되어, 이후 추가한 치환 규칙이 다시 적용되지 않습니다.
